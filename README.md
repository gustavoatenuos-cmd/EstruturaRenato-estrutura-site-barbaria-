# Lanzinnis — site oficial

Nova versão do site da Lanzinnis construída em React + TypeScript + Vite + Tailwind.

## Estrutura
- Hero com foco na marca
- Seção principal de prótese capilar masculina
- Comparador interativo de antes/depois
- Processo: avaliação, aplicação e manutenção
- Serviços tradicionais de barbearia
- WhatsApp, Instagram e endereço

## Rodar localmente
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
